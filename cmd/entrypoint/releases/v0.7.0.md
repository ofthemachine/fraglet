# Release v0.7.0

## Key Highlights

- **Argv mode** — `execution.argv: true` in `fraglet.yaml` skips file injection entirely and execs `execution.path` directly against a literal argv. For containers with no interpreter at all (`FROM scratch`: a single static binary plus `fraglet-entrypoint`, no shell).

## New Features

### Argv mode

Injection and script/interpreter execution assume there's a file to inject into and a shell (or interpreter) to run it — that doesn't hold for a `FROM scratch` image built from a single static binary. `execution.argv: true` handles that case instead:

- **No fraglet mounted** (a plain `docker run image <args>`): CLI args pass straight through to `execution.path`, unmodified — the image still works as an ordinary CLI container.
- **A fraglet is mounted** (a `fragletc` invocation): the mounted body must be exactly one command line. It's tokenized and expanded to a literal argv — whitespace words, `'single'`/`"double"` quoting, `$VAR`/`${VAR}`/`$@`/`$1..$9` — and exec'd with no shell involved either way. The body's first word must name `execution.path`; a mismatch fails loudly instead of silently exec'ing the wrong argv.
- Deliberately unsupported: pipes, redirects, `;`/`&&`/`||`, command substitution, globbing. Use script/injection mode if you need those — argv mode errors immediately on the first such character rather than producing a plausible-looking but wrong command.

```yaml
execution:
  path: /meme-cli
  argv: true
```

See `containers/meme` (sibling `ofthemachine/containers` repo) for a working example: a `FROM scratch` image wrapping the `meme-cli` static binary with no shell at all.

## Reproducible Builds

To verify a release binary was built from the claimed source:

```bash
./verify-release.sh entrypoint-v0.7.0
```

This runs the build inside a `golang:<version>-bookworm` container pinned to the exact Go version from `go.mod` at the tag, builds both linux/amd64 and linux/arm64 binaries, and outputs sha256 checksums. Compare against `checksums.txt` from the release.

## Upgrading

```dockerfile
ARG FRAGLET_VERSION=entrypoint-v0.7.0
```

Update the sha256 checksums to match the new release binaries.
