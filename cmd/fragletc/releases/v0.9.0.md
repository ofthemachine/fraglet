# fragletc v0.9.0

## Key Highlights
- **Host-side required parameter enforcement** — `param=<alias>:required` declarations are now validated host-side before any container starts, failing fast with exit code 2 and a clean parameter listing instead of running with unset variables.
- **Default value exemption** — declaring `default=` on a parameter satisfies the presence requirement, exempting it from missing-parameter errors.

## What's New

### Host-Side Required Parameter Enforcement

When a script declares parameters with `:required`, `fragletc` now checks all supplied `-p` / `--param` arguments before starting any container:

```python
#: param=name:required
#: param=format:default=json
```

If a required parameter is omitted:

```bash
$ ./script.py
missing required parameter(s): name

Parameters for script.py:
  format       (optional, default: json)
  name         (required)

See --fraglet-help for the full description.
```

### Why This Matters

Previously, omitting a required parameter allowed `fragletc` to launch the container regardless. Inside the container, missing parameters simply expanded to empty strings in environment variables, producing obscure runtime exceptions or confusing inner-tool usage errors.

Validation now runs entirely on the host before container execution, providing immediate feedback in milliseconds.

### Semantics

- **Missing parameters exit with code 2**, matching standard CLI argument validation conventions.
- **`default=` exempts `required`**: If a parameter declares a default value, it is treated as satisfied even if the caller does not explicitly provide `-p`.
- **Targeted validation**: Parameter presence is checked strictly against `-p` / `--param` flags. Raw `-e` environment forwarding remains an independent pass-through mechanism.

## Reproducible Builds

To verify a release binary was built from the claimed source:

```bash
./verify-release.sh fragletc-v0.9.0
```

This runs the build inside a `golang:<version>-bookworm` container pinned to the exact Go version from `go.mod`, downloads the release's `build-info.json`, builds all platform binaries, and outputs sha256 checksums. Compare against `checksums.txt` from the release.
