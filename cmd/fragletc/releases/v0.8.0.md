# fragletc v0.8.0

## Key Highlights
- **Removed the built-in MCP server and `pkg/save` CAS.** `fragletc mcp` is gone. Fraglet execution and caching for AI-agent tool-calling now live in `operon`'s tooly mesh, which already invokes fraglet's own `pkg/engine` directly (no MCP indirection) and has a more capable, ledger-backed cache. fraglet goes back to being what it's for: a bare execution primitive — CLI + Go library, nothing else.

## Breaking Changes

### `fragletc mcp` subcommand removed

`fragletc mcp` and `fragletc mcp --save=<path>` no longer exist. There is no replacement MCP server shipped from this repo. If you were pointing Claude Desktop or Cursor at `fragletc mcp`, that integration is gone; fraglet-tool invocation for AI agents now happens through `operon`'s tooly mesh instead.

### `pkg/save` deleted

The `ArtifactSaver` interface and `LocalSave` content-addressed store (`root/lang/[tag/]h[:2]/h[2:]`, SHA256-keyed) are removed from the Go module. If you imported `pkg/save` directly, that package no longer exists.

### Dependency drop

`github.com/modelcontextprotocol/go-sdk` (and its transitive dependencies) is no longer a dependency of this module.

## Reproducible Builds

To verify a release binary was built from the claimed source:

```bash
./verify-release.sh fragletc-v0.8.0
```

This runs the build inside a `golang:<version>-bookworm` container pinned to the exact Go version from `go.mod`, downloads the release's `build-info.json`, builds all platform binaries, and outputs sha256 checksums. Compare against `checksums.txt` from the release.
