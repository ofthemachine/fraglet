# fragletc v0.17.0

## Key Highlights
- **A fraglet can say a failure is temporary**: exit 75 (EX_TEMPFAIL), and `--retry N` runs it again, waiting 1s, 2s, 4s… (jittered) in between.
- **`--timeout D` bounds a run**, retries and waits included: a run it ends exits 124, its container removed, its receipt saying so.
- **A failed run's receipt says why**: `stderr` (a digest, every run) and `stderr_tail` (the last lines of a failed run's stderr, secret values masked). A run fragletc could not start (a missing image, no Docker) still gets a receipt, exit 1, with the error.

## What's New

### Temporary failures: exit 75 and `--retry`

A rate limit (HTTP 429) or a server down for a moment used to fail a run like any bug. A fraglet that exits 75 now says "try again", and only fragletc decides how often:

```
fragletc --retry 2 web/wiki-summary.py -p query="cat behavior"
fragletc: exit 75 (temporary): retry 1 of 2 in 700ms
```

A retry is just another run: only the last run's stdout, outputs and receipt count; each run reads the same stdin and starts with an empty `/output`. Nothing else is retried, so a fraglet that is not safe to run twice simply never exits 75 (the exit code is the opt-in). Without `--retry`, 75 is an exit code like any other.

### `--timeout`

`--timeout 90s` ends the whole run (every retry and wait) after 90 seconds. Every container is now named, so ending a run removes its container too: killing the docker client alone used to leave it running.

### Receipts (`fraglet-receipt/2`, additive)

| Field | When | What |
|---|---|---|
| `stderr` | always | digest of the run's stderr, beside `stdout` |
| `stderr_tail` | failed runs | its last whole lines of stderr, at most 2 KiB, every secret value masked |

The memo key formula is unchanged, so the schema stays `fraglet-receipt/2`: a reader that does not know the new fields loses nothing.

### Library

- `pkg/engine`: `RunWithRetry`, `Retry`, `ExitTempFail`, `ExitTimeout`.
- `pkg/receipt`: `Outcome.Stderr`, `Outcome.StderrTail`, `Tail`.
- `pkg/fraglet`: shebang lint knows `--retry` and `--timeout`.
