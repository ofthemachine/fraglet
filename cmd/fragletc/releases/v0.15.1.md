# fragletc v0.15.1

## Key Highlights
- **Receipts no longer carry your directory.** `procedure` is the script's file name (`transform.py`), not the path it was run from (`/Users/<you>/work/tools/transform.py`).

## What's Fixed

### `--receipt`: `procedure` is a file name

A receipt travels: it is cited in rooms, bundled with documents and handed to other machines to attest. Run directly (through its shebang), a script reaches fragletc as the absolute path the caller typed, so every receipt recorded the runner's home directory, user name and folder layout. `procedure` was only ever a label for readers; the script's identity is `procedure_hash`, which is unchanged, as are the memo key and every other field. Stdin (`-`) is kept as given.

### Library

- `pkg/receipt`: `Build` keeps the procedure by its file name (`filepath.Base`).
