# fragletc v0.12.0

## Key Highlights
- **`fragletc lint`** — check fraglet headers against fragletc's own grammar. The parser that runs your script is the parser that lints it, so there is nothing to keep in sync.
- **`--strict`** — promote convention warnings (missing `description=`, missing `network=`, a param the body never reads) to errors, for CI and catalog builds.

## What's New

### `fragletc lint [--strict] <script-or-dir>...`

```
$ fragletc lint tools/news/rss-headlines.py
tools/news/rss-headlines.py: warning: network-missing: no #: network= line; declare network=none (enforced hermetic) or network=required
tools/news/rss-headlines.py:3: warning: param-no-description: param=feed has no description; add :d=<what the caller should pass>
tools/news/rss-headlines.py:4: warning: param-no-description: param=count has no description; add :d=<what the caller should pass>
tools/news/rss-headlines.py:4: warning: param-optional-redundant: param=count: optional is the default and does nothing; omit it
1 file linted, 0 errors, 4 warnings
```

A file named explicitly is always linted. A directory is walked and only files whose shebang invokes `fragletc` are linted (hidden directories skipped), so `fragletc lint tools/` covers exactly the scripts fragletc would run.

**Errors** are declarations fragletc misreads or silently drops:

| Rule | What it catches |
|---|---|
| `param-desc-not-last` | `description=`/`d=` followed by another modifier — it was swallowed into the prose |
| `param-unknown-modifier` | anything outside `required`, `optional`, `file`, `default=`, `envvar=`, `description=`/`d=`; also `default`/`envvar` without a value |
| `param-required-with-default` | `default=` silently exempts `required` (`fraglet.MissingRequired`) |
| `param-alias` | alias must be `[a-z][a-z0-9_]*` — it becomes the env var; a dotted suffix (`source.tex`) only with `:file` |
| `param-duplicate` | same alias twice — the first wins, the rest are dropped |
| `network-value` | `network=` other than `none` / `required` |
| `output-relpath` | absolute, `..`, or duplicate `output=` paths |

**Warnings** are conventions (errors under `--strict`):

| Rule | What it catches |
|---|---|
| `param-no-description` | a param with nothing to show in `--fraglet-help` |
| `param-optional-redundant` | bare `optional` — a no-op |
| `param-unused` | the body never references the param's env var (`ALIAS` uppercased, or `envvar=`) — a plain substring check, the only thing lint infers from the body across every target language |
| `network-missing` | no `network=` line |
| `desc-missing` | no tool-level `d=` line |

Exit code: 0 clean, 1 on any error (or any warning with `--strict`), 2 on usage.

## Upgrade Notes
- Purely additive; no change to how scripts run. `optional` remains accepted by the runner — `lint` only points out that it does nothing.
