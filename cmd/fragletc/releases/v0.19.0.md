# fragletc v0.19.0

## Key Highlights
- **A script answers for the secrets it prints**: when the value of a secret a run was given appears in its stdout, stderr or a file under `/output`, the run fails by default, the value masked. A script's header may say otherwise: `#: secret-output=redact` (masked, the run succeeds) or `#: secret-output=uncensored` (kept as written).
- **The receipt says so**: `secret_output` records the mode and every place a secret appeared, by name, in every mode; the receipt's digests are of what was delivered, after the mode applied.
- **`--streams DIR`** saves the run's stdout and stderr exactly as its receipt hashes them, so whoever publishes a receipt can publish everything it names.

## What's New

### `#: secret-output=fail|redact|uncensored`

```
#: secret=COHERE_API_KEY:d=Cohere API key
#: secret-output=redact
```

What a run writes passes a guard before anything sees it: the caller, a capture, the receipt's hash. It reads left to right, the longest value first, so a value split across writes is caught and one inside another is masked whole. Files under `/output` are read before they are hashed. `Execute` (the library) holds a script to its mode as the CLI does. An unknown mode refuses the run; `fragletc lint` flags it (`secret-output-value`).

### `--streams DIR`

`DIR/stdout` and `DIR/stderr` are the run's streams as its receipt names them, never fragletc's own messages; with `--retry`, the last run's.

### Upgrading

A tool that prints a secret it was given now fails. Stop printing it, or declare `#: secret-output=redact` or `uncensored` in its header.
