# fragletc v0.15.0

## Key Highlights
- **`kind=` param modifier**: a param declares what its value is (`color`, `enum(a|b)`, `range(0..100,5)`, …) so a caller can offer the right input and check a value before running.
- **`receipt.Key`** is now exported, so every consumer computes the one memo key instead of re-deriving it.

## What's New

### `#: param=NAME:kind=…` — typed params

```
#: param=hex:kind=color:d=Light color
#: param=on:kind=enum(on|off|toggle)
#: param=bri:kind=range(0..100,5):default=50
```

- **Closed vocabulary:** `string`, `text`, `number`, `integer`, `range(min..max[,step])`, `enum(a|b|c)`, `bool`, `color`, `date`, `datetime`, `file`, `secret`.
- **Wire format is unchanged.** A value is still a string; the kind says which strings are allowed. Undeclared, a param is a string (a file with `:file`).
- **Canonical values.** A color normalizes to `#rrggbb` (accepts `#rgb` and names like `orange`), a bool to `true`/`false`, an enum to its declared spelling.
- **New lint rule `param-kind`** (error): an unparseable `kind=`, or a `default=` that does not satisfy it. `kind=` joins the known modifiers, and writing `description=` before it is caught as swallowed prose.

### Library

- `pkg/fraglet`: `Kind`, `ParseKind`, `Kind.Normalize`, `ParamDecl.Kind()`.
- `pkg/receipt`: `memoKey` is now exported as `Key(procedureHash, params, inputs)`. The formula and known answers are unchanged.
